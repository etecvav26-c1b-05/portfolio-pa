#  Sistema de Lanchonete

Projeto desenvolvido em **Python** para simular um sistema simples de lanchonete.

## Funcionalidades

* Cadastro de produtos
* Controle de estoque
* Realização de pedidos
* Cálculo do total
* Visualização de produtos e pedidos
* Salvamento dos dados em JSON

## Tecnologias

* Python
* JSON
